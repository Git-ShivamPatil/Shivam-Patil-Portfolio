# shivamsfolio

An editorial, systems-inspired portfolio built with Next.js, React, CSS, and Node.js.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm run start
```

## Pages

- `/` — Home and selected work
- `/projects/[slug]` — Six detailed project case studies
- `/contact` — Introductory contact page
- `/reach-out` — Email, LinkedIn, WhatsApp, phone, GitHub, and résumé

The latest SDE-II résumé is available at `/Shivam-Patil-SDE-II-Resume.pdf`.
